# A generated index cannot drift

**Gate:** `ci/gates/index_drift.py`

An index derived from other notes is generated by a tool, tracked, and byte-identical to a fresh regeneration. It declares that it is generated and names its tool; a hand edit is detected as drift.

## Why

Recorded in the gate's own module docstring, which states the defect this prevents and what the check does not decide.

The gate's failure output names this note, so tripping it hands you the rule rather than a verdict.
Read [`ci/gates/index_drift.py`](../../../ci/gates/index_drift.py) for exactly what it decides — and, where it
matters, what it deliberately does not.
